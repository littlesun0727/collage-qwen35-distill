# 拼贴结构评测指标与计算协议 v1

当前主协议已更新为 [五项主指标 v2](METRICS_V2.md)。本文保留为兼容诊断指标定义。

协议：`collage-structure-eval-v1.1`。v1.1 同时输出逐模板均值与全量累计，不改变单图匹配和计分。正式 GT 与业务验收线尚未冻结；旧 EVALUATION_DRAFT.md 只保留讨论历史。

## 指标总览

共 8 项评测维度：5 项主指标、2 项基础检查、1 项辅助指标。每项可包含多个读数，不合成为一个总分。

| 定位 | 指标 | 判断什么 | summary.json 全量累计路径 |
| --- | --- | --- | --- |
| 主① | 不看类别的检测 P/R/F1@0.50 | 元素有没有找到，是否漏拆、多拆 | `detection` |
| 主② | 匹配元素分类准确率、混淆矩阵 | 找到后角色是否正确 | `classification` |
| 主③ | 匹配元素平均 IoU＋覆盖率 | 框多准、多少元素被覆盖 | `localization` |
| 主④ | 关系 P/R/F1@0.50 | 相框承载、出框关联是否正确 | `relations.photo_id`、`relations.linked_to` |
| 主⑤ | 确定遮挡对正确率@0.50 | 必须满足的前后顺序是否正确 | `occlusion_order` |
| 基础 | 背景类型准确率、混淆矩阵 | 摄影、固定、纯色、透明背景 | `background` |
| 基础 | JSON 合法率、核心结构合法率 | 格式、ID、引用、顺序是否可用 | `validity` |
| 辅助 | 四类分别计算的 IoU-weighted F1 | 每类的整体检测质量 | `auxiliary_iou_f1` |

所有 JSON 分数为 0–1，报告显示为百分比。`null` / N/A 表示无适用分母或缺少必要标注，不是零分或满分。

## 汇总方式：主看逐模板均值，全量累计作对照

| 汇总 | 算法 | 每张图的权重 | 使用方式 |
| --- | --- | --- | --- |
| 逐模板均值（per-image macro） | 每图先计算该指标，再对有定义的图求算术平均 | 每个适用模板相同 | 主报告 |
| 全量累计（micro / pooled） | 累加全数据集计数或IoU，再代公式 | 元素、匹配或关系多的图更大 | 对照报告 |

逐模板均值 = Σ单图分数 / 适用图片数。对1000张图上均有定义的指标，分母就是1000；不能把未定义的关系/层级分数强行填0或1。
F1必须先逐图算F1再平均，不能先平均P/R再计算F1。

主视图位于 `per_template_macro`，每个读数都有 `mean / eligible_images / total_images`。
例如 `per_template_macro.detection.f1.mean`；原顶层 `detection.f1` 仍是全量累计值，保持v1接口可用。report.md 将两种口径并列。

- 检测：有GT但缺失/损坏预测的图，F1=0，进入平均，不能跳过失败。
- 分类准确率、mIoU：没有匹配的图无条件分数，不进入条件均值；必须一起报告匹配覆盖率、检测成绩及适用图片数。该均值不能单独代表整体能力。
- 关系：GT或预测有该类关系时计算；双方均无不进入平均；无GT但虚构关系的图以F1=0进入平均。
- 遮挡：仅有人工约束的图有分数。已审无约束和未审均不进入分数平均，但审核覆盖分别统计。
- 辅助四类IoU-F1：该类GT或预测非空的图进入均值，双方均空不奖励满分。
- 背景/合法率：每图一个0/1判断，两种汇总结果相同。

DAD公开IoU-F1入口逐图计算后平均；COCO AP则在类别内汇总所有图的检测、按置信度计算PR/AP，再跨类别/IoU阈值汇总。后者不是逐图AP平均，也不等同于本工程micro-F1。不存在适用全部任务的唯一汇总方式。

## 1. 输入与评价范围

评价原始 `structure.json`，不使用后处理后的 `analysis.json` 替代模型预测。
核心字段为 background、objects 的 id/kind/bbox/photo_id/linked_to，以及 layer_order。
objects 类别固定为 photo / frame / overlay / text，background 不加入元素框分母。
模型对象 ID 可以与 GT 不同，不能直接比较 ID 字符串；通过实例匹配建立对应。

当前 1000 张教师输出来自：
`data/teacher-delivery`。
它们是未人工核验的候选 GT，以其打分只代表与教师的一致性。
GT 缺失、损坏或结构非法会终止运行，不静默删掉或修复。

这版不评价 description 中人数、姿态、选材与归属语义，也不评价 OCR 内容、文字样式、像素级图层恢复。核心结构合法不等于完整上游 schema 或所有业务语义正确。

坐标统一到 0–1000 的 xyxy 水平外接矩形。默认 normalized_1000，也支持显式 normalized_1 / pixel；pixel 需在输入记录提供 width、height。不猜单位、不裁剪越界框、不交换颠倒坐标。

框的语义遵守上游 `collage/prompts/analyze.md`：保留环境的 photo 框完整照片窗口，不只框人物；抠图 photo 框完整主体组合；frame 框完整框体；overlay/text 按既定完整单元规范处理。阴影、描边、组合点缀和载体印字的粒度须统一，不能直接换成 DAD 的所有元素 amodal 标注口径。

## 2. 三种匹配

IoU = 交集面积 / 并集面积。所有匹配均一对一，一个预测不能认领多个 GT。

| 匹配 | 使用指标 | 候选条件 | 优化目标 |
| --- | --- | --- | --- |
| A：几何匹配 | 检测、分类、定位 | 不看 kind，IoU ≥ 0.50 | 匹配数量最多，其次 IoU 总和最大 |
| B：类别相关匹配 | 关系、遮挡 | kind 相同，IoU ≥ 0.50 | 匹配数量最多，其次 IoU 总和最大 |
| C：同类软匹配 | 辅助 IoU-F1 | 同一 kind，正 IoU，无 0.50 门槛 | IoU 总和最大 |

A/B 使用匈牙利算法：有效边赋权 K+1+IoU，K=min(GT数,预测数)，无效边赋权0。这样优先保留最多有效对应，而不是最大化原始 IoU 后再删低于门槛的配对。

主①②③共用 A，主④⑤共用 B，不能为关系或层级另外挑有利的匹配。B 的关联端点还须有唯一有效 ID。错分类会影响端到端关系/层级成绩。

精确并列由输入数组顺序与 SciPy 的确定性分配处理，不加入 ID 文本、关系或层级作为打分依据。记录 SciPy 版本。
近乎同框的照片与相框，纯几何不一定能判断实例身份，因此检测与分类不能声称完全独立。`details.potential_geometry_ties` 记录局部等 IoU 替代候选，提示人工复核；它不是完备歧义检测，不自动排除样本或改分。

## 3. 主①：检测 P / R / F1

令 A 匹配数为 T、预测对象数为 M、GT 对象数为 N：

```text
TP = T
FP = M - T
FN = N - T
Precision = TP / (TP + FP)
Recall = TP / (TP + FN)
F1 = 2TP / (2TP + FP + FN)
```

类别错但位置能匹配，仍算元素找到。重复预测/过度拆分增加 FP，合并独立元素通常增加 FN。
主视图先逐图计算F1再平均。全量累计视图则先累加所有TP/FP/FN再计算（micro），两者均输出。
`per_gt_class` 另报每个 GT 类别的召回率和支持量。

## 4. 主②：分类准确率与混淆矩阵

```text
分类准确率 = A匹配中 kind 正确的数量 / A匹配总数
```

只看已匹配元素；漏检不进入这个条件分母，必须同时看检测召回率。
未知或缺失 kind 进入预测 `__invalid__` 列，不从分母删除。
混淆矩阵行是 GT，列是预测。主视图平均各图有定义的条件准确率；全量累计视图累加所有匹配后求准确率。没有匹配时为 N/A，不进入条件均值。
`per_gt_class` 另报各类条件分类准确率。

## 5. 主③：平均 IoU 与覆盖率

```text
mean IoU = A匹配对 IoU 总和 / A匹配总数
coverage = A匹配总数 / GT对象总数
```

主视图先在图内计算平均IoU再跨适用图平均；全量累计视图累加全部匹配IoU和匹配数。门槛为0.50，故只反映门槛以上的框；低于门槛的定位失败还会降低检测召回率。
例如只匹配到 10 个 GT 中的 2 个，mIoU=0.95、coverage=0.20，不能解释为整图定位质量95%。
无匹配时 mean IoU=N/A；有 GT 却无匹配时 coverage=0。

## 6. 主④：关系三元组 F1

```text
(frame, photo_id, photo)
(foreground_photo, linked_to, base_photo)
(foreground_photo, linked_to, photographic_background)
```

frame 的 photo_id 有几个成员就展开为几条关系。
一条关系得 TP，要求两端通过 B 匹配，且连接对象、关系类型、方向都正确。
摄影背景是特殊节点：预测与 GT 均为 photographic、预测正确引用自身合法背景 ID 时对应；不要求背景 ID 字符串相同，不计算背景 bbox。

```text
TP = 正确关系数
FP = 预测关系数 - TP
FN = GT关系数 - TP
F1 = 2TP / (2TP + FP + FN)
```

连错对象通常同时产生 FP 和 FN。非法来源类别、无效引用、错误字段形式不能得 TP，可枚举的错误关系计 FP。
重复关系只得一次分，多余重复计 FP，结构合法性也不通过。
photo_id / linked_to 分别报逐模板F1均值与全量累计P/R/F1，同时报GT关系数、GT图片数、预测数量。没有GT但预测关系时F1=0并进入平均；双方均无关系时N/A，不平均大量空图满分。
不自动评价 description 中自由文本表达的归属。

## 7. 主⑤：确定遮挡对正确率

额外 GT 字段 occlusion_pairs，每对方向为 `[下方元素ID, 上方元素ID]`：

```json
{"id":"0004","occlusion_pairs":[["photo_card","frame_music"],["frame_music","photo_card_foreground"]]}
```

只标人工确认的直接遮挡约束，不自动补传递闭包、不加入背景天然在底层的配对。不从完整排序枚举所有元素对，也不凭 bbox 相交生成遮挡 GT。

令 GT约束数=Q、两端均正确匹配且顺序正确的数量=C：

```text
端到端遮挡对正确率 = C / Q
条件排序准确率 = C / 已匹配且两端顺序可唯一确定的约束数
元素对覆盖率 = 已匹配且两端顺序可唯一确定的约束数 / Q
```

端点漏检、错分类、定位未达门槛、ID重复、排序中缺端点或重复端点，都不能得分。
没有遮挡要求的元素交换顺序不扣分。主视图平均有约束图片的C/Q；全量累计视图为ΣC/ΣQ。另报审核图片数、有效对数。

未标注必须与“确认没有遮挡对”区分：

- 省略或 null：未审核，不参与该项，其他指标正常计算。
- []：已审核且没有适用对；没有分母，不计满分。
- 非空列表：参与计分。

层级成绩只代表已标注部分；未提供标注则为 N/A。`--require-occlusions` 要求每张图片都完成审核，允许 []。
GT配对必须引用独立对象，不可自指、重复或与 GT layer_order 矛盾，发现问题终止评测。
这是 POA 思路的任务适配，不宣称完全复刻 DAD 尚未完整公开的 POA 实现。

## 8. 两项基础检查

背景类型准确率 = background.type 正确的图片数 / GT图片数。
四类为 photographic / reference_clean / solid_color / transparent；缺失或非法类型算错，另报混淆矩阵。不评价颜色值精度、背景描述或清底效果。

预测存在率、JSON合法率、核心结构合法率的分母均为固定 GT图片数。核心检查包括：

- 根对象、objects列表、background对象、layer_order字符串列表；
- 合法 kind，有限且范围正确的 bbox，非空且唯一对象ID；
- 摄影/固定背景有ID，背景ID不与对象冲突，纯色背景有 #RRGGBB；
- frame非空photo_id数组、linked_to字符串形式、引用目标与来源类别；
- layer_order恰好包含所有对象一次，不包含背景或未知对象。

严格 JSON 拒绝重复键、NaN/Infinity；不从自然语言/Markdown代码块自动提取 JSON。额外字段可保留但不计分，不校验完整文本样式/description业务语义。

## 9. 辅助：四类 IoU-weighted F1

对每个 kind 独立进行 C 匹配，令 IoU总和=S_k、GT数=N_k、预测数=M_k：

```text
IoU-weighted F1_k = 2S_k / (N_k + M_k)
```

每类先逐图计算，主视图对适用图求均值；同时累计每类S/N/M得到全量累计对照。不再平均四类、不使用DAD text20%/visual80%权重。
双方均空为 N/A；只有一边有元素为0。非法框占预测数量但没有 IoU贡献。
未知类别不强归四类，其错误由检测FP、分类invalid列、合法率体现，不能只凭辅助分选模型。
这版与 DAD 共用计分思想，但类别、汇总、空集合处理均不同，不直接与论文成绩横向比较。

## 10. 失败处理与可复现性

| 情况 | 行为 |
| --- | --- |
| GT损坏、重复样本ID、未知预测样本ID | 终止，先修正输入 |
| GT样本缺预测、模型文本无法解析 | 保留样本，按无有效预测处理，相应元素/关系漏检、背景错、合法性失败 |
| 部分预测字段损坏 | 不静默修复；有效部分可评价，坏框/非对象条目仍占预测数量，无效关系计FP，合法性失败 |
| 检测两边均空 | F1=N/A，累计0个TP/FP/FN |
| 分类/定位无匹配 | 条件准确率/mIoU=N/A，覆盖率按GT计算 |
| 双方无该类元素/关系 | 对应F1=N/A，不奖励空集 |
| 无遮挡审核 | N/A或只报已标注部分，明确审核覆盖 |

JSONL外层必须有可识别 id；损坏到无法归属样本的外层记录会终止读取。推荐将原始模型文本放在外层 structure 字符串中，使坏模型JSON仍可按id计分。

保存协议版本、门槛、GT/预测/遮挡指纹、代码SHA-256、Python/NumPy/SciPy版本、模型名与运行名。输入、GT或协议改变后须重评基线。模型提示词、采样设置及checkpoint还需由推理流程固定记录，评分器不调用模型。

## 11. 验证与当前数据支持量

合成测试覆盖漏检、多检、错分类、错连、重复关系、背景关联、反序、非法输出、坐标转换、空分母、样本覆盖及匹配优化目标。
现有1000条候选教师GT可完整读取：14,080个objects、654条photo_id关系、32条linked_to关系。512是frame对象数，列表展开后有654条关系；linked_to分布在25张图。
教师对自身比对仅为工程自检，不是模型能力成绩。没有人工遮挡对时不产生层级分。
正式冻结前仍需人工审查拆分粒度、近同框歧义、遮挡约束；稀少关系的小幅成绩波动不宜直接解释为稳定提升。
